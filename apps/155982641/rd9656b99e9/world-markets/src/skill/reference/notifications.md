# Notifications

Attention is scarce. **One unprompted non-critical message per week** (Sunday digest). Guardian pushes exempt from bundling. Routine renewals silent (digest only). Receipts name silence conditions.

| Event | Channel |
|---|---|
| Guardian breach | Push, immediate |
| Failed/partial exec · loan renewal failure | Push p2 |
| Negative-carry flip | Push |
| Policy block | Inline to request |
| P&L · risk · dollarpower | Digest only |

Priority: urgent risk > failed exec > policy > user > progress > opportunity. No yield pitches during urgent risk.
