# ATLAS

One available-margin figure; liquidation when it cannot support the risk. Inputs: spot notional, 98% lender haircut, unrealized perp PnL, hedged netting, minus 10-day borrow interest. Equal spot + short perp nets directional risk. Unproven post-trade RAPV → fail closed. Negative RAPV = eligibility.
